This document outlines the optimal, zero-cost technology stack for the AI-Powered Alcohol Label Verification prototype.Language: Python 3.11+.OCR Engine: EasyOCR. It runs locally without API keys, bypassing strict outbound federal firewalls and ensuring rapid processing speeds.Computer Vision/Preprocessing: OpenCV (opencv-python-headless). Used to auto-rotate images, mitigate glare via Contrast Limited Adaptive Histogram Equalization (CLAHE), and smooth pixelation on low-quality mobile uploads.String Matching: RapidFuzz. A C++ optimized library that calculates Levenshtein distances quickly, allowing for calibrated flexible matching (e.g., "STONE'S THROW" vs "Stone's Throw").User Interface: Streamlit. Provides a highly accessible drag-and-drop interface with zero learning curve and native batch upload support.Data Handling: Pandas. Structures the verification results for easy sorting by severity and provides one-click CSV exports.Deployment: HuggingFace Spaces (Free Tier). Provides free hosting and CPU resources to run the prototype seamlessly for a job application demo.
